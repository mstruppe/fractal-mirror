## 3. Ontology — ONT (what exists)

*Settled by C-017 (Ratified); recorded here against the older model (decision C-052).*

A node's **shell is behaviour, not class**: the same Entity, one identity, can wear either face —

- **Galaxy — the container face.** Open it and see what is placed inside (containment edges pointing in). The "GS" of the ChatGPT-era UI vision.
- **Operator — the application face.** Invoke it; inputs flow in, outputs flow out, and **a run appends provenance edges** — the log records not just where things sit but how they were made. The "OS" of the ChatGPT-era vision; the capability/plug-in thinking of Master Index Parts VIII (capability contracts, typed ports, adapters) remains the richest exploration of this face and is inherited as *direction*, pointer-only.

**Supersession record (C-052):** the ChatGPT-era *current two-shell model* — Galaxy Shell and Operator Shell as two fundamental object **classes** (its ledger item 69.5) — is superseded by C-017's two-**faces**-of-one-node. The Master Index's open questions 13.8 ("can a shell change class?") and 13.9 ("can one object embody both roles?") are thereby answered: yes, trivially — faces are worn, not assigned; both faces share one Entity and one set of Relationships. This is what makes the reversible split-screen navigation of the UI vision possible at all.
