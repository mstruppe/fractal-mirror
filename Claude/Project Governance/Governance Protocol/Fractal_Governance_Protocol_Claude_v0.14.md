## 5. Jointly Derived Conclusions

1. **A map can be canonical without being fat.** The Architecture State is authoritative for *what is current and what supersedes what*; every section defers detail to the canonical document that owns it. This resolves the tension between "self-sufficient tome" (the ChatGPT-era ambition) and recursive simplicity — the same move that made the Global Context a stable two-section pole.
2. **Supersessions must be written down where the old model lived.** C-017 had quietly outmoded the two-class shell model for six days of ratified life; nothing recorded it against ledger item 69.5 or TBDs 13.8/13.9. An architecture map earns its keep exactly here.
3. **Honest holes beat implied coverage.** The WS section *declares* that no Claude-era canonical exists and names the forge trigger, rather than routing readers into empty folders. The route exists so work has an address; the address does not pretend to be a building.
4. **Root rank is a worldview statement.** `AST` joins the six roots because the architecture is a genuine top-level domain; `ONT`/`WS`/`PROT` sit where the Index already said they belong. One `AST.*` scan now traces the whole architecture.
