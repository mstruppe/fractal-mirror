## Repo rituals (Code surface)

- **Commits — author and committer both carry meaning (C-037 + C-084):** **author = whoever wrote the bytes.** On this surface that is `Claude <claude@fractal.local>` for everything Claude writes; `Max Struppe <max.struppe@gmail.com>` only for what Max writes himself. **Committer = whoever authorized this act:** `Claude` when acting inside permissions already granted (the standing push, C-064, or anything within this adapter's grant); **`Max Struppe` when Max actively commands or ratifies** — typing `/close`, saying *go* on a decision. Custody is the **signature**, always Max's key (C-074b) — so *author Claude, committer Claude, signed by Max* is the normal shape for standing-authority work, and is not a defect. Set both explicitly; never let the git default decide. Message `[DOMAIN] imperative summary` + decision refs; one commit per coherent change-set — the commit is the event boundary (C-025). No history rewriting on shared state.
- **Personal-class material routes to the annex, never here (C-098, re-weighing C-085):** the private `fractal-annex` repo is the default home of personal/working material — the notebook moved there 2026-08-16; this history is public-bound. Should any personal-class file ever re-enter this repo, the C-085 rule stands: Max authors it, Max commits it, **a close never stages it**. Report it and move on.
- **A secret's value never enters the repo (C-087):** no canonical artifact — store, log, governed document, committed config — ever holds a secret value. The *fact* of a credential (name, purpose, scope, holder, lifecycle) is knowledge and is recorded; the **value** lives in the environment layer (`.gitignore`d env file or OS keychain). Secrets are deliberately non-durable: rebuild = re-issue against the recorded facts, never restore.
- **Releases are provenance-anchored (C-090):** a shipped release is a **signed tag at a close** plus an **external timestamp attestation** of it (OpenTimestamps; attestation + receipt live in the root folder Provenance), committed with the close and carried by its push. Executed by the governing surface at the tagging close; escalations (eIDAS, registration) at need. The anchor-authority set is an instance value (the ninth parameter, GENESIS §2).
