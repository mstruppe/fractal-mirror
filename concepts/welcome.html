Command library

welcome

First contact, scripted. The one moment every project meets a stranger is the one moment least safe to improvise — so it isn’t.

What happens

The session first determines where it is standing, with one read-only command. A distribution clone — a copy at a release tag, anything that is not the governing repository — makes the session a reference surface: it may read, explain, and assist a birth, and it may never close, edit canon, or push. The governing repository itself gets a different greeting: this is the live project; working sessions open with its own opener. The distinction is stated in one friendly sentence, not a wall of rules.

Then the explanation, written for a user rather than an evaluator: your project gets a memory that survives every session — decisions recorded with their reasoning, work handed over so any future session picks up cold, all of it plain text in git that you own. The AI works inside rules you can read; nothing is hidden in chat history.

Then exactly two paths out. Start my own project leads into the onboarding interview (begin) and ends in a repository of your own. Show me around gets an oriented tour — answered from the corpus, citing what was read, loading only what the question needs. Common first questions — what a clone contains versus what an instance inherits, which version to use, what the two permission layers are — are answered briefly, and only if asked.

Why it’s shaped this way

The first shipping run found the opening moment unscripted, and the finding became a command — the same route every part of the system takes from friction to fix. Two rules do the real work here: a session must know whether it governs or merely references before it acts, and it must orient by reading the named entry points, never by scanning the repository.

The shipped file: welcome.md ↓ — the baseline’s own working copy, verbatim. It compresses the Onboarding Protocol and the reference-surface rule; the stamp at its foot names its sources and refresh triggers, like every governed file.
